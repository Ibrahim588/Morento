# Morento | مورينتو — Luxury Chocolate & Flowers Boutique
### متجر الهدايا الفاخرة — جدة، حي الروضة

متجر إلكتروني فاخر صُمم خصيصاً لبوتيك **مورينتو (Morento)** في حي الروضة بمدينة جدة، المملكة العربية السعودية. يجمع المتجر بين الشوكولاتة البلجيكية الفاخرة وتنسيقات الورد الطبيعي، مع واجهة ثنائية اللغة (عربي RTL افتراضياً، وإنجليزي LTR)، وإمكانية تخصيص بطاقة الإهداء وحجز موعد التوصيل عبر الواتساب المباشر.

---

## 🌟 الميزات الرئيسية

- **واجهة فاخرة معاصرة (Editorial Luxury Design):** لوحة ألوان دافئة مستوحاة من بني الشوكولاتة العميق، العاجي الدافئ، عنابي الورود، والذهب الشامباني.
- **ثنائي اللغة بالكامل (Bilingual RTL / LTR):** العربية كلغة رئيسية مع مبدل فوري للغة الإنجليزية وتنسيق اتجاه الصفحة كاملاً.
- **كتالوج هدايا تفاعلي (`/catalog`):**
  - تصنيف الهدايا (شوكولاتة فاخرة، شوكولاتة مع ورد، بوكسات هدايا، فازات وتنسيقات، هدايا مناسبات).
  - فلترة سريعة حسب المناسبة (تخرج، ذكرى زواج، عيد ميلاد، ضيافة VIP).
  - بحث لحظي بالاسم والوصف بالعربية والإنجليزية مع إعادة ضبط سريعة.
  - ترتيب حسب السعر والمقترح.
- **صفحة تفاصيل الهدية (`/product/[slug]`):**
  - معرض صور عالي الدقة.
  - توضيح الأسعار الاسترشادية وعدد القطع ووقت التجهيز.
  - زر تخصيص فوري للإهداء.
- **محرك تخصيص الإهداء وحجز الموعد (Gift Customizer):**
  - اسم وهاتف صاحب الطلب مع التحقق من الصيغ السعودية.
  - بيانات المستلم مع خيار "هدية مفاجأة".
  - تحديد تاريخ التوصيل المفضل ومنع التواريخ الماضية.
  - تحديد حي التوصيل بجدة ووقت التوصيل.
  - كتابة رسالة الإهداء للطباعة على بطاقة مورينتو الفاخرة.
- **ربط ذكي ومباشر بالواتساب (`+966 56 777 6011`):**
  - تشفير رسائل الـ URL بدقة ونقل جميع بيانات التخصيص والملاحظات دون الحاجة لقواعد بيانات أو بوابات دفع.
- **سلة هدايا خفيفة (Gift Drawer):** تتيح جمع عدة منتجات وتعديل الكميات وإرسال طلب مجمع عبر الواتساب.
- **التوافق التام مع سيو ومحركات البحث (Technical SEO):**
  - بيانات منظمة (Schema.org LocalBusiness & Florist) بالتقييم الرسمي 4.8 من 190 مراجعة على خرائط جوجل.
  - خريطة الموقع `sitemap.xml` وملف `robots.txt`.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (مع لوحة ألوان مخصصة)
- **Icons:** Lucide React
- **Typography:** IBM Plex Sans Arabic (للعربية) و Cormorant Garamond / Inter (للإنجليزية)
- **Data Layer:** Centralized structured local data (`src/data/`)

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# 1. الدخول إلى مجلد المشروع
cd c:\Projects\Morento

# 2. تثبيت الحزم (إن لم تكن مثبتة)
npm install

# 3. تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 📦 بناء نسخة الإنتاج واختبارها (Production Build)

## 🌐 النشر على الإنترنت (Deployment)

المشروع جاهز 100% للنشر الفوري على منصات الاستضافة الحديثة:
1. **Vercel (الموصى به لـ Next.js):**
   - اربط مستودع GitHub بحساب Vercel واضغط **Deploy**.
   - لا توجد أي متغيرات بيئية سرية مطلوبة للمرحلة الحالية.
2. **Netlify أو Cloudflare Pages:**
   - أمر البناء: `npm run build`
   - مجلد الإخراج: `.next`
